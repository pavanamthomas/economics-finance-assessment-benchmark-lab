# Distractor taxonomy

Tags live in `src/efablab/taxonomy.py`. Every incorrect option on an accepted item must carry one of them. The keyed option carries `CORRECT_KEY`.

The tag is a claim about the *error in that option*, not a psychometric estimate of how often examinees make it.

| Tag | Typical failure |
| --- | --- |
| SIGN_REVERSAL | Raise when one should release; convexity read as risk aversion |
| NECESSARY_VS_SUFFICIENT | Zero MM profit forces \(\lambda=0\); randomisation repairs demand |
| LEVEL_VS_MARGINAL | λ as a profit; equal utility as equal rents |
| STOCK_VS_FLOW | LCR as NSFR; origination LTV as a perpetual floor |
| PARTIAL_VS_GENERAL_EQUILIBRIUM | Jobs in a place as welfare; wages as MPL across cities |
| WRONG_INFORMATION_SET | Insider observes \(p\); mid-mark as a fill |
| CORRELATION_VS_IDENTIFICATION | Imbalance forecast as take-alpha; univariate hedonic as WTP |
| TIMING_ERROR | CCyB release in a boom; public mempool as already filled |
| WRONG_DENOMINATOR | \(R'=-t\) not \(-t/q\); majority of supply not of votes cast |
| INCORRECT_NORMALIZATION | \(k\) as a price; VaR as ΔCoVaR |
| VIOLATED_ASSUMPTION | Inventory required for a GM spread; tick size required for Kyle λ |
| APPROXIMATION_OUTSIDE_RANGE | Linear IL at \(r=4\); infinitesimal fill at \(\Delta x/x=0.1\) |
| EQUILIBRIUM_FEEDBACK_IGNORED | Freeze as Nash; quotes already jumped by the forecast |
| PRIVATE_VS_SOCIAL_COST | Micro solvency as system stability |
| NOMINAL_VS_REAL | Hide marks, restore efficiency |
| AVERAGE_VS_MARGINAL_EXECUTION_PRICE | Spot as a CPAMM fill; mid as a take |
| RISK_VS_UNCERTAINTY | Diversification removes delegated-capital risk |
| LIQUIDITY_VS_SOLVENCY | Fire sale as LCR-only; LCR labelled a capital ratio |
| RANKING_VS_PROBABILITY | Three uncorrected stars as replication |
| STATIC_VS_DYNAMIC_EFFECT | Permanent impact “already in VWAP”; sticky quotes as \(m\) fixed |
